# Theme Switcher Webpage

This project is a simple webpage that allows users to switch between different CSS themes representing the 70s, 80s, 90s, 00s, and the current era. The webpage features centered text displaying "Megan Laurie UX/UI Designer," along with buttons for theme selection and links to social media profiles.

## Project Structure

```
theme-switcher-webpage
├── css
│   ├── 70s.css        # Styles for the 1970s theme
│   ├── 80s.css        # Styles for the 1980s theme
│   ├── 90s.css        # Styles for the 1990s theme
│   ├── 00s.css        # Styles for the 2000s theme
│   ├── now.css        # Styles for the current theme
│   └── styles.css     # Default styles for the webpage
├── js
│   └── themeSwitcher.js # JavaScript for handling theme switching
├── index.html         # Main HTML document
└── README.md          # Project documentation
```

## Features

- **Theme Selection**: Users can choose from five different themes by clicking the corresponding buttons.
- **Centered Text**: The webpage prominently displays "Megan Laurie UX/UI Designer."
- **Social Links**: Buttons linking to GitHub, LinkedIn, and a contact page are included.

## Usage

1. Clone the repository to your local machine.
2. Open `index.html` in a web browser.
3. Click on the theme buttons to switch between different styles.
4. Use the social media buttons to navigate to the respective profiles.
